## What is Bidya PM

Most AI tools act as simple text generators. They churn out bloated PRDs and speculative stories that flood engineering sprint backlogs without answering if this drives real business value.

Bidya PM is a product management intelligence system built for Antigravity Claude Cursor Codex and Gemini. It operates as a senior product advisor that:

1. Separates symptoms from true functional needs before tickets are created
2. Deconstructs initiatives into thin vertical slices to validate risk in days
3. Applies evaluation hygiene to non deterministic AI features
4. Enforces outcome telemetry to prevent vanity gaming

## Core Functional Capabilities

### 1. Demand Decoding (/decode-demand)
Sales and executive requests often arrive as pre packaged solutions. This workflow:
* Maps the literal request to the root job to be done
* Scores strategic drift against active quarterly bets
* Generates lean counter proposals addressing the root cause
* Delivers objective communication scripts to manage stakeholder expectations

### 2. Opportunity Mapping (/opportunity-map)
Feature roadmaps often decouple engineering work from top level business goals. This workflow:
* Builds structured opportunity solution trees connecting north star metrics to user friction
* Separates low risk optimizations from high impact exploratory bets
* Sets up rapid 48 hour hypothesis probes and fail fast signals

### 3. Thin Tracer Vertical Slicing (/slice-deliverable)
Monolithic epics deliver zero user value until completely finished. This workflow:
* Slices large capabilities into thin deployable vertical increments
* Writes strict Gherkin acceptance criteria
* Attaches telemetry event schemas with explicit success thresholds

### 4. AI Feature Evaluation (/ai-product-eval)
Teams often treat AI features like deterministic code and ship brittle user experiences. This workflow:
* Evaluates whether non deterministic models are actually needed over simple heuristics
* Defines golden evaluation datasets and error limits
* Designs fallback pathways for low confidence states
* Sets up explicit and implicit telemetry loops to refine model performance

## The Bidya Product Axioms

1. Outcomes over output. Velocity without telemetry is just high speed waste.
2. Deconstruct before delivering. Treat every request as a symptom not a specification.
3. Tracer bullets over mega specs. Build the thinnest testable slice that resolves uncertainty.
4. AI era pragmatism. Prioritize evals and fallback states over static designs.
5. Constructive friction. Respectfully challenge assumptions and demand evidence before execution.
